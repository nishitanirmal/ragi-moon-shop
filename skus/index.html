How the code works

RM-SW-AMB-200G: RM is Ragi & Moon, SW is the type (SV savoury, SW sweet, GF gift), AMB is three letters for the product, 200G is the pack size (G grams, PC pieces). The same product in a new size keeps its three letters. A flavour changes the last letter (BRV vanilla, BRC chocolate). Every SKU needs its own barcode.
